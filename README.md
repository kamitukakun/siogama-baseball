# 塩竈少年野球団 公式サイト

宮城県塩竈市の少年野球団・学童野球チームの公式ホームページです。

## 公開方法（GitHub Pages）

1. GitHubリポジトリの **Settings → Pages** を開く
2. **Source** で `Deploy from a branch` を選択
3. Branch を `main` / `/(root)` にして保存
4. 数分後に `https://<username>.github.io/<repo>/` で公開されます

## ファイル構成

- `index.html` — トップページ
- `support.js` — ページ描画用ランタイム
- `images/hero-shiogama.png` — ヒーロー画像
